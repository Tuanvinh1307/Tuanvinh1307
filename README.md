## Dự án nổi bật

### VN-Traffic-Instance-Segmentation-YOLO11
Repository chính thức phục vụ xây dựng bộ dữ liệu giao thông đô thị Việt Nam (BDD100K-ViSeg) và bài toán Instance Segmentation sử dụng YOLO11, SAM 2 và công cụ gán nhãn CVAT.

Nội dung chính:
- Quy trình thu thập và tiền xử lý dữ liệu ảnh giao thông
- Pipeline gán nhãn bán tự động với SAM 2 kết hợp CVAT
- Huấn luyện và đánh giá mô hình YOLO11 cho instance segmentation
